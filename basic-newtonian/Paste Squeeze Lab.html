Live profiles through the paste

Time0 ms
Profile collapse: for a thin layer of uniform thickness h, T(z/h, t) depends only on Fo = αt/h². Every paste column therefore shares one profile, and the steady profile is linear in z/h for any final geometry. Geometry changes h, coverage, and total column conductance, not the one-dimensional profile shape. Air-filled columns (dashed) reach the same steady line but respond faster because their α is larger.
